SCHEMA v1 - VIRTUAL EXPERIMENT ONLY

Each TXT record: JSON object per line; schemaVersion=1, simulation=true,
runId, type, UTC epoch-ms at. This is a research dataset, not trained model weights.

session: rule configuration, baseline virtual SOL, fee/rent/fill assumptions.
candidate: mint/pool, discovery source, firstSeenAt; absent fields stay null.
snapshot: mint/pool, minute0/1/5/15/30/60, observedAt, onTime,
priceSol/USD, mcap, liquidityUSD, volume5m, buys/sells, change5m, source.
decision: input values, risk/account VIRTUAL state, rule checks/thresholds,
score (coverage, not win probability), verdict, unavailable reasons.
quote_unavailable / quote_unverified / fill_rejected: no virtual fill occurred.
virtual_fill: unique order and position IDs; BUY/SELL, raw quantity,
quote timestamp/provider, assumed minimum output, fee/rent, partial/full exit,
net realized PnL, position PnL only when closed. No on-chain signature exists.
sampled_outcome: sampled maximum gain / minimum return / return60m,
anchor timestamp, sample count/max gap. Label=UNVERIFIED_SAMPLED_ONLY.
These are not continuous extrema, executable exits or independently verified rugs.

Daily report TXT: configuration, period/cutoff, virtual net realized PnL,
fees, wins/closed, current virtual portfolio with reportObservedAt,
coverage/drop counts and retained JSONL records. equityAtCutoff=null unless
verified; current equity must not be read as historical cutoff equity.

Analysis deduplicates order IDs and compares initial virtual-position features
between virtual winners and losers. This is not a causal filter audit or evidence
that skipped tokens would have been tradable. Under200closed: insufficient sample.
Never mix simulation=true rows with LIVE receipts as real execution evidence.

MOMENTUM5M v1 (2026-10-31):
strategy_change: from/to versions, configuration, policy history timestamp.
virtual_fill.strategyVersion and position.strategyVersion partition old/new runs.
New input signal: change_5m_pct, signal_at, source_venue, migrated_pool,
signal_window_coverage. Provider-reported changes are not reconstructed candles.
No holder/dev/social evidence is required or certified in momentum mode.
Order principal=1SOL; stop price=0.7*initial entry; TP fractions of INITIAL raw
quantity=50/20/20/final remainder at2x/3x/5x/10x. Final sale closes rounding dust.
position.tpSoldSteps persists only after confirmed virtual sale; restart cannot
repeat a completed tranche. Fees/rent and cash conservation remain unchanged.

V2 correctness + research gates (not fitted to historical trades):
entry_confirmation: samples/span/rise/pullback/lastAt from bounded fresh prices.
entry_roundtrip: exact min-output tokens, reverse min-output SOL, two assumed
network fees, impact per leg. No sell route -> no BUY. Min-output loss is a
conservative scenario, not measured slippage or expected realized cost.
entryLocks: persistent per-mint consumed signal, last exit and fresh negative
reset timestamps. Changing pool or restarting does not clear a consumed cycle.
SELL trigger: original entry price, trigger price/time/multiple and quote delay.
accounting: exact lamport cash/basis/rent/realized-PnL conservation check.
policyHistory keeps v1 results distinct from v2. No old trade is re-priced or
loss erased by an upgrade. All claims remain simulation-only, not real receipts.

MEME-SCALP v1:
Hourly scalp-YYYY-MM-DD-HH.jsonl.gz decompresses to JSONL. Every A admission
is logged; async candidate_progress and execution rows carry the same cycle/
signal identity, reached stage, reason, A/B/C/D/E measured metrics.
D_INFRA rows explicitly quality_rejection=false; no token-bad inference.
forward_outcome stores +1/+5/+15m sampled returns/extrema, null if missing.
hourly_funnel counts observations/attempts; not unique-token win probabilities.
AI context and output remain null. All rows simulation=true, never live receipts.

Stream the gz archives with analyze.js; fill order IDs deduplicate across copies.
